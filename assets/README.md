# Assets

Bahan yang dipakai **bersama** oleh banyak episode.

## Struktur yang Disarankan

```
assets/
├── textures/   ← Tekstur kertas tua, watercolor, noda tinta
├── overlays/   ← Film grain, debu, vignette, kebocoran cahaya
├── music/      ← Musik latar
├── sfx/        ← Efek suara (angin, api, langkah kaki)
├── fonts/      ← Font gratis (Cinzel, Cormorant, EB Garamond)
└── branding/   ← Logo, intro, outro channel
```

## Aturan Lisensi ⚠️

- Pakai hanya bahan **gratis untuk komersial** atau yang dibuat sendiri.
- Catat sumber & lisensi setiap file di `assets/LICENSES.md` (dibuat saat file pertama ditambahkan).
- Bahan khusus satu episode disimpan di folder episode, bukan di sini.
