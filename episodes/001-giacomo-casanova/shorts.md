## Prinsip Shorts Channel

1. **Detik pertama = hook.** Teks besar di layar langsung memancing rasa penasaran.
2. **Teks berjalan (subtitle) selalu tampil**, karena banyak orang menonton Shorts tanpa suara.
3. **Satu ide per Shorts.** Satu kisah, atau satu pesan.
4. **Ajakan di akhir: menonton video lengkap**, bukan membeli apa pun (episode 001–005 tanpa jualan).

## Tata Letak: "Halaman Buku Vertikal"

Gambar kita berformat lanskap, jadi Shorts memakai tata letak khusus yang tetap
cocok dengan gaya channel, **tanpa perlu membuat gambar baru**:

```
┌───────────────────────┐
│   kertas tua (kode)   │
│                       │
│   TEKS HOOK / JUDUL   │  ← Cinzel, emas antik
│                       │
│ ┌───────────────────┐ │
│ │                   │ │
│ │  gambar lanskap   │ │  ← gambar dari video panjang, zoom & geser pelan
│ │                   │ │
│ └───────────────────┘ │
│                       │
│  subtitle berjalan    │  ← Cormorant tebal, krem; kata yang sedang
│  kata demi kata       │     dibaca menyala emas
│                       │
│   The Art of Being    │  ← logo kecil
│        a Man          │
└───────────────────────┘
```

- **Close-up (C1, C2)** boleh tampil **penuh layar** (dipotong vertikal) karena subjeknya di tengah.
- Gambar diperbesar (*upscale*) sebelum dipakai agar tetap tajam.
- *(Opsional, nanti)* Jika hasilnya kurang memikat, buat 1 gambar vertikal tambahan per Shorts khusus untuk frame pembuka.
