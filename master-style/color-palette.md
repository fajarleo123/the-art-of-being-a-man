untuk menjaga konsistensi seluruh channel.

## Aturan Mode Poster: 4–5 Warna per Gambar

Setiap gambar Mode Poster memakai susunan seperti ini:

| Peran | Porsi | Pilihan warna |
|---|---|---|
| **Gelap dominan** | ±50% | Biru Malam Pudar / Hitam Arang / Burgundy Tua |
| **Menengah** | ±30% | Cokelat Kulit / Hijau Zaitun Tua / Krem Pudar |
| **Terang** | ±15% | Krem Kertas / Emas Antik (cahaya) |
| **Aksen** | ±5% | **Burgundy Gelap** (jubah Marcus) atau Merah Karat (Cassius) |

> 💡 **Ciri khas channel:** dalam setiap gambar tempat Marcus muncul,
> **jubah burgundy-nya adalah satu-satunya warna merah tua yang menonjol**,
> sehingga mata penonton selalu langsung menemukannya, meski tokohnya kecil.

## Suasana per Jenis Adegan

| Suasana | Dominan |
|---|---|
| Malam / renungan | Biru Malam Pudar + cahaya lampu Emas Antik |
| Konflik / perang | Hitam Arang + Burgundy Tua, aksen api Emas Antik |
| Fajar / harapan | Krem Kertas + Emas Antik, bayangan Biru Malam Pudar |
| Kilas balik | Semua warna lebih pudar, condong ke Krem Pudar (sepia) |
| Dunia modern (Pria Tanpa Zaman) | Hitam Arang + Biru Malam Pudar, cahaya tepi Emas Antik |

## Catatan

- Kode HEX ini akan disalin ke satu file tema di `remotion/` agar warna teks,
  efek, dan transisi selalu sama persis.
- Jika hasil AI warnanya menyimpang, warna bisa dikoreksi dengan kode
  (*color grading*) agar kembali ke palet ini.
