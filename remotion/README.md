# Remotion (Belum Dipasang)

Folder ini nanti berisi proyek **Remotion** — alat gratis & open-source
untuk membuat video menggunakan kode (React).

## Rencana Fungsi

- Merakit layer ilustrasi menjadi animasi parallax 2.5D
- Menerapkan gerak kamera sesuai `master-style/animation-rules.md`
- Menggunakan warna dari `master-style/color-palette.md`
- Menyelaraskan animasi dengan voice-over
- Render video akhir (MP4)
