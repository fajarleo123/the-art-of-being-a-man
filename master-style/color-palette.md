# Palet Warna — The Art of Being a Man

Gunakan **hanya** warna di bawah ini (atau variasi terang/gelapnya)
untuk menjaga konsistensi seluruh channel.

## Warna Utama

| Nama | HEX | Peran |
|---|---|---|
| Burgundy Gelap | `#4A0E1A` | Warna khas channel, bayangan hangat, kain/jubah |
| Burgundy Tua | `#2B0A10` | Bayangan terdalam, vignette |
| Cokelat Kulit | `#5C3A21` | Kayu, kulit, tanah |
| Cokelat Tinta | `#2E1F14` | Garis tinta, teks gelap |
| Krem Kertas | `#E8DCC4` | Latar kertas, teks terang |
| Krem Pudar | `#C9B79C` | Kertas tua, sorotan lembut |
| Emas Antik | `#B08D57` | Aksen, cahaya, judul |
| Emas Redup | `#8A6D3B` | Ornamen, bingkai |

## Warna Pendukung (pakai secukupnya)

| Nama | HEX | Peran |
|---|---|---|
| Hitam Arang | `#141010` | Latar paling gelap (hindari hitam murni `#000000`) |
| Hijau Zaitun Tua | `#3F4A2E` | Alam, daun, padang |
| Biru Malam Pudar | `#1F2A36` | Langit malam, suasana dingin |

## Pembagian Proporsi (Aturan 60-30-10)

- **60%** — Gelap: Hitam Arang, Burgundy Tua, Cokelat Tinta
- **30%** — Menengah: Burgundy Gelap, Cokelat Kulit, Krem Pudar
- **10%** — Aksen: Emas Antik, Krem Kertas (cahaya & fokus mata)

## Suasana per Jenis Adegan

| Suasana | Dominan |
|---|---|
| Renungan / malam | Biru Malam Pudar + cahaya lilin Emas Antik |
| Konflik / perang | Burgundy Gelap + Cokelat Kulit, kontras tinggi |
| Kebijaksanaan / penutup | Krem Kertas + Emas Antik, lebih terang |
| Kilas balik | Semua warna sedikit pudar (sepia) |

## Catatan

- Kode HEX ini nanti akan disalin ke file kode di `remotion/` agar warna
