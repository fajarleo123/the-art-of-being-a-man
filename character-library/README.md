# Character Library

Perpustakaan lembar karakter. Tujuannya agar setiap tokoh **selalu terlihat
sama** di setiap adegan dan episode.

## Aturan

- Satu file per tokoh, nama file huruf kecil dengan tanda hubung:
  `marcus-aurelius.md`, `miyamoto-musashi.md`.
- Gambar referensi disimpan di subfolder bernama sama:
  `character-library/marcus-aurelius/`.
- Ikuti gaya di `master-style/visual-guide.md`.
