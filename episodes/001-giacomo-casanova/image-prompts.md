# Paket Prompt Siap Tempel — Episode 001: Giacomo Casanova

> **Status:** 🟡 Draf — menunggu persetujuan
> **Gaya:** Campuran (Mode Poster + 2 Close-up) · lihat `master-style/visual-guide.md`
> **Total gambar:** **25** (3 referensi + 20 poster + 2 close-up)
> **Dipakai di adegan:** lihat `storyboard.md`

## Cara Pakai di ChatGPT (dari HP)

1. Kerjakan **berurutan per gelombang**. Gelombang 1 wajib selesai dan disetujui dulu.
2. Jika kolom **"Lampirkan"** berisi kode gambar (mis. `R1`), lampirkan gambar itu dulu, lalu tempel prompt.
3. **Salin seluruh isi kotak prompt** (tekan lama → pilih semua → salin), lalu tempel.
4. Hasil belum pas? Minta perbaikan singkat, misalnya:
   *"Keep everything the same, but make the coat deep burgundy, not bright red."*
5. Simpan gambar terpilih dan ganti namanya sesuai kolom **"Nama file"**.
6. Upload ke GitHub di folder `episodes/001-giacomo-casanova/images/`
   (Chrome → Add file → Upload files; aktifkan **Situs desktop** bila tombol tidak muncul).
7. Kabari Claude. Gambar akan dicek terhadap kolom **"Cek wajib"** sebelum dipakai.

**Penting:** semua tulisan (judul, kutipan, kalimat di kaca jendela, nama kota) **ditambahkan
dengan kode**, jadi gambar AI **tidak boleh** berisi huruf yang terbaca.
